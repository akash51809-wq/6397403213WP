FAQ
Questions, answered clearly.

  

    
WhatsApp API क्या है?
WhatsApp API आपके software को messaging workflows से connect करने का तरीका है, ताकि applications programmatically messages और related events handle कर सकें।

    
API कैसे मिलेगी?
API access और setup आपके selected plan और backend configuration पर निर्भर करेगा। शुरुआत के लिए API documentation देखें।

    
कितने numbers connect कर सकते हैं?
यह आपके account plan और backend की configured limits पर निर्भर करेगा। उपलब्ध limits pricing या account setup के समय स्पष्ट की जाएंगी।

    
क्या bulk messaging supported है?
हाँ, product workflow में bulk messaging capability को support करने के लिए dedicated messaging tools और recipient workflows रखे गए हैं।

    
क्या scheduling उपलब्ध है?
Scheduling को messaging और campaign workflows के हिस्से के रूप में organize किया जा सकता है। उपलब्ध limits और execution rules आपके deployment पर निर्भर करेंगे।

    
क्या API documentation available है?
हाँ, public API documentation page उपलब्ध है। Detailed endpoints और integration examples वहीं रखे जाएंगे।

    
क्या plans बदल सकते हैं?
Plan changes account और billing rules पर निर्भर करेंगे। वर्तमान options pricing page पर देखें।

    
Support कैसे मिलेगा?
Support channel और response process आपके business plan और deployment setup के अनुसार उपलब्ध कराया जाएगा।
