WhatsApp API Documentation

Static examples for integrating message and group messaging endpoints.

01

Send Message API

Send a WhatsApp message to a single recipient.

POST
POST https://your-domain.com/api/message/send

Request Body

{
  "number": "+919876543210",
  "message": "Hello from API",
  "session": "main"
}

Response

{
  "success": true,
  "message": "Message sent"
}
02

Send Message in Group

Send a WhatsApp message to a selected group.

POST
POST https://your-domain.com/api/group/message/send

Request Body

{
  "groupId": "120363012345678901",
  "message": "Hello group",
  "session": "main"
}

Response

{
  "success": true,
  "message": "Group message sent"
}
API Base URLReplace your-domain.com with the domain where your WhatsApp API is hosted.
