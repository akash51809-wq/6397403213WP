# ERS SMS Gateway - Android App (Kotlin)

**ऐप का नाम:** ERS SMS  
**पैकेज आईडी:** `com.sms.gateway`  
**वर्जन:** 1.0.0  

यह एंड्रॉइड ऐप आपके स्मार्टफोन को एक शक्तिशाली **SMS Gateway** में बदल देता है। इसके जरिए आप अपने वेब पैनल से सिम कार्ड के माध्यम से सीधे एसएमएस भेज सकते हैं और मोबाइल पर आने वाले एसएमएस को तुरंत वेब पैनल पर लाइव प्राप्त कर सकते हैं।

---

## 🌟 मुख्य विशेषताएं (Features)

1. **वेब पैनल से डायरेक्ट एसएमएस भेजना (Outbound SMS):**
   - वेब पैनल / API से सिंगल या बल्क एसएमएस भेजना।
   - 160 अक्षरों से अधिक लंबे मैसेज के लिए ऑटोमैटिक मल्टीपार्ट एसएमएस विभाजन।
   - डिलीवरी रिपोर्ट (Sent, Delivered, Failed) तुरंत वेब पैनल को रिपोर्ट करना।

2. **इनकमिंग एसएमएस कैप्चर (Inbound SMS):**
   - फोन पर आने वाले सभी एसएमएस को तुरंत WebSocket के माध्यम से वेब पैनल पर लाइव फॉरवर्ड करना।
   - प्रेषक का नंबर, मैसेज टेक्स्ट, समय, और सिम स्लॉट की पूरी जानकारी।

3. **ड्यूल सिम सपोर्ट (Dual SIM):**
   - सिम 1 या सिम 2 को प्राथमिकता देने का विकल्प।
   - ऑटोमैटिक डिफ़ॉल्ट सिम का विकल्प।

4. **24x7 बैकग्राउंड सर्विस (Foreground Service):**
   - फोन की स्क्रीन बंद होने पर भी लगातार बैकग्राउंड में एक्टिव रहना।
   - फोन रीस्टार्ट होने पर ऑटो-स्टार्ट (Boot Receiver)।
   - बैटरी ऑप्टिमाइज़ेशन बाईपास का विकल्प।

5. **QR कोड स्कैनिंग पेयरिंग:**
   - वेब पैनल के QR कोड को एक क्लिक में स्कैन करके सर्वर और API Key कॉन्फ़िगर करना।

6. **शून्य बाहरी निर्भरता (Zero External Dependencies):**
   - किसी महंगे Firebase FCM की आवश्यकता नहीं।
   - डायरेक्ट हल्का WebSocket कनेक्शन।

## 🚀 एंड्रॉइड स्टूडियो में कैसे चलाएं (How to Open in Android Studio)

1. **Android Studio** खोलें।
2. **Open** पर क्लिक करें और इस फ़ोल्डर को चुनें:  
   `d:\projects\mobile SMS app\ers-sms-android`
3. Gradle Sync पूरा होने दें।
4. **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** पर क्लिक करें।
5. निर्मित APK आपके फोन में इंस्टॉल करने के लिए तैयार हो जाएगा (`app/build/outputs/apk/debug/app-debug.apk`)।
